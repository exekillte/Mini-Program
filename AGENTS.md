# AGENTS.md

## Purpose

This repository is the canonical source for public-safe personal scripts, apps, and reusable configurations. Do not assume this repository is private.

## Mandatory workflow for agents

1. Read `catalog.json`, `README.md`, and [the delivery policy](docs/FILE_DELIVERY_POLICY.md) before changing an existing program.
2. Prefer one stable canonical download path per program; update the contents of that path instead of making multiple `final_v2_v3` files.
3. Preserve old versions in Git commit history. Do not rewrite history to simulate a replacement.
4. Verify generated files, avoid accidentally overwriting a newer revision, and read back changes after a successful GitHub write.
5. Update version metadata, catalog, and download links when appropriate; keep README pointing to the latest stable path.
6. Never put private or personal documents, student identities, credentials, tokens, cookies, or private network subscriptions into this **public** repository.
7. If an intended upload is unsupported or unavailable, state explicitly that the GitHub backup is incomplete; provide a verified local deliverable instead.
8. Do not claim that a raw-link update automatically installs or removes software on user devices.

See [docs/FILE_DELIVERY_POLICY.md](docs/FILE_DELIVERY_POLICY.md) for detailed Chinese-language rules.
